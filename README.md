# OS On Linux
## What it does.
Installs: Android, Windows (Vmware or VirtualBox), and Other
## How to install.
1. Open Terminal
2. Run (If you don't have these): 
```
sudo apt install sh sudo wget -y # Ubuntu/Debian
sudo dnf install sh sudo wget # Fedora/Rhel
sudo pacman -Sy sh sudo wget # Arch Linux
```
3. To Install It Run:
```
curl -fsSL "https://github.com/WinDaBest/os-on-linux/raw/refs/heads/main/os-on-linux.sh" | sh
```
If that doesent work run "wget https://github.com/WinDaBest/os-on-linux/raw/refs/heads/main/os-on-linux.sh && sh os-on-linux.sh"

4. Select what you want.
5. Boom your done!
